# Reprojection (C++17)

使用理想针孔模型计算三维点的重投影像素坐标，并与观测点比较像素欧氏距离。

## 约定

- 外参：`Pc = R * Pw + t`（世界到相机）
- 内参：`fx, fy, cx, cy`
- 忽略畸变
- 三维坐标与平移量单位一致

## 构建

```bash
mkdir -p build && cd build
cmake ..
make
## 测试用例

程序内置 4 个用例：

1. 光轴点 —— 重投影落于光心，误差 0
2. 观测偏移 10px —— 验证误差计算
3. 偏离光轴 —— 验证投影公式
4. 非正深度 —— 验证异常处理（返回无效）
